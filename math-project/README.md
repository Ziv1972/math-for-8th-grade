# תרגול מתמטיקה כיתה ח' 📐

ערכת כלים לתרגול מתמטיקה לכיתה ח' (עברית, ספר "שבצת"), לקראת מבחן מועד ב'.

## מבנה התיקייה

```
math-project/
├── CLAUDE.md          ← מסמך ההעברה המלא (קרא קודם!) — קונטקסט ל-Claude Code
├── README.md          ← הקובץ הזה
├── exams/             ← מבחנים ומשחק (קבצי HTML עצמאיים)
│   ├── game.html      ← 🎮 משחק תרגול (8 עולמות, XP, ניאון) — לתרגול שוטף
│   ├── exam.html      ← מבחן 1 (מסכם)
│   ├── exam2.html     ← מבחן 2 (דגש מערכות משוואות)
│   ├── exam3.html     ← מבחן 3 (קשה)
│   ├── exam4.html     ← מבחן 4 (קשה מאוד)
│   ├── exam5.html     ← מבחן 5 ⭐ (מעקב ביצועים מלא + דוח AI) — הכי חדש
│   ├── tirgul.html    ← תרגול בסיסי (הסבר + תרגילים)
│   └── tirgul.jsx     ← גרסת React ראשונה (נטושה)
└── skill/             ← הסקיל לבניית תוכן (hebrew-math-grade8-tutor)
    ├── SKILL.md
    ├── references/    ← נושאים, מאגר תרגילים, סכמה, SVG, נוסחאות
    └── assets/        ← תבנית מבחן
```

## הרצה מהירה
פתח כל קובץ `.html` בדפדפן (דאבל-קליק). הכל עצמאי, ללא התקנה.

## להמשך פיתוח
1. קרא את **`CLAUDE.md`** — הוא מכיל הכל: ארכיטקטורה, סכמת תרגיל, באגים שתוקנו, החלטות עיצוב, ומשימות פתוחות.
2. `git init` מומלץ לפני שינויים.
3. כל תשובה חדשה במבחן — **אמת ב-Python** לפני שמשלבים (ראה CLAUDE.md §5).

## המשימה הבאה
הילד/ה ניגש/ת ל-`exam5.html` → לוחץ/ת "העתק נתונים לניתוח" בסוף → מדביק/ה את הדוח ל-Claude → קבלת ניתוח + בניית תרגול ממוקד על נקודות החולשה.
